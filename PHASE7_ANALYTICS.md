# Digitalora Phase 7 — Advanced Analytics

Adds an admin-only analytics layer without changing financial or order business logic.

## Included
- 24h / 7d / 30d analytics views
- Orders, units, buyers, revenue and average order value
- Approved deposit count and amount
- Pending deposit count
- Low-stock and out-of-stock active product counts
- New users in the selected period
- Top customer by paid-order spend
- Stable `adm:analytics` callback IDs
- Existing detailed Stats view remains available

No database migration is required.
